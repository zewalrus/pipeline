# Theme Page Studio

A phone-first planner for running theme pages on Instagram and Facebook.

- **Today**: what to post today, open slots for the next 7 days, and what is working
- **Ideas**: an idea bank with law-of-attraction prompts
- **Posts**: build reels (hook, beats, audio), carousels (up to 20 slides) and image posts, with caption, call to action and hashtag sets. One tap copies the caption for each platform
- **Plan**: a weekly calendar that flags days with no post
- **Kit**: brand settings, hashtag sets, content pillars, hook bank, calls to action, backup and sync

Install it from the browser (Add to Home Screen). Sync uses Firebase. Settings are in `firebase-config.js`.
